Welcome to the Balafon Transcription System's development page! Here, you can find the Arduino code, KiCad models of electronic hardware, and current transcription algorithm.

For hardware assembly & operation instructions, visit the User Manual: https://docs.google.com/document/d/1rZsZTW_g_-hbK4d2u1pkhDDZRovUMO_R9wST9ffC6Lw/

Learn more about the purpose of this system and the hardware development process here: https://journeys.dartmouth.edu/katelynhadley/balafon-transcription-system/

The Balafon Transcription System is being developed by Katelyn Hadley, Rebecca Abraham, and Dr. Andrew McPherson in support of Dr. Laura McPherson's research on speech surrogates at Dartmouth College.<br/> <br/>
